## Install (beta) / Установка беты

🇬🇧
0. ⚠️ **If you already have the Steam Workshop version of Lore-Hardcore installed — UNSUBSCRIBE from it on the Workshop, or disable it in the launcher.** Do NOT run the Steam version and the beta at the same time (two copies of the same module = conflicts / the wrong one loads).
1. Make sure you have the required base mods installed (Harmony, ButterLib, UIExtenderEx, MBOptionScreen, **TOR / The Old Realms — WITM 1.16**).
2. Download the latest beta build from this repository (the `LoreHardcore/` folder or the release archive).
3. Copy the `LoreHardcore` folder into `...\Mount & Blade II Bannerlord\Modules\` (replace if asked).
4. Enable **LoreHardcore** in the launcher, below TOR_Core. Launch.
5. ⚠️ Back up your saves first — beta builds can break save compatibility.

🇷🇺
0. ⚠️ **Если у вас уже установлена Steam-версия Lore-Hardcore — ОТПИШИТЕСЬ от неё в Workshop или отключите в лаунчере.** НЕЛЬЗЯ запускать Steam-версию и бету одновременно (две копии одного модуля = конфликты / загрузится не та).
1. Установите базовые моды (Harmony, ButterLib, UIExtenderEx, MBOptionScreen, **TOR / The Old Realms — WITM 1.16**).
2. Скачайте свежую бета-сборку из этого репозитория (папка `LoreHardcore/` или архив релиза).
3. Скопируйте папку `LoreHardcore` в `...\Mount & Blade II Bannerlord\Modules\` (с заменой).
4. Включите **LoreHardcore** в лаунчере, ниже TOR_Core. Запускайте.
5. ⚠️ Сначала сделайте бэкап сохранений — бета может ломать совместимость сейвов.

## Bug reports / Баги
🇬🇧 Found a bug in the beta? Please report it with: the version (shown in the main menu, e.g. `v0.1.9.56`), what you did, and the log file `rgl_log_*.txt` from `C:\ProgramData\Mount and Blade II Bannerlord\logs\`.

🇷🇺 Нашли баг в бете? Сообщите: версию (видна в главном меню, напр. `v0.1.9.56`), что делали, и лог `rgl_log_*.txt` из `C:\ProgramData\Mount and Blade II Bannerlord\logs\`.
